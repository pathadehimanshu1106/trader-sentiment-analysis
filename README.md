Trader Performance vs Market Sentiment

Objective:
Analyze how Bitcoin Fear-Greed sentiment impacts trader profitability, win rate, volatility, and trading behavior.

Tools Used:
Python, Pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook

Files:
analysis.ipynb -> Complete analysis notebook
analysis.html -> Exported report
fear_greed_index.csv -> Sentiment data
historical_data.csv -> Market sentiment dataset
historical_data.csv -> Trader history dataset

## Dataset

The historical trading dataset is large and cannot be hosted directly on GitHub.

Download it from Google Drive:
https://drive.google.com/file/d/1APHU-acPuqTzBGqsYe-U9hT12nvcb7-1/view?usp=sharing


Key Insights:
- Extreme Greed shows highest average PnL and win rate.
- Fear days show highest trading activity.
- Volatility is higher during Extreme Greed and Extreme Fear.
- Position size varies with sentiment regime.

How to Run:
1. Open analysis.ipynb in Jupyter Notebook.
2. Run all cells sequentially.
